# GPT-test
This repo is a clone of <https://github.com/modichirag/GPT-opt/tree/polar>. The main changes are in the `gptopt/optim/mach_polar.py` file but most files have small changes to make it work with the new algorithm.

See README.md file in <https://github.com/modichirag/GPT-opt/tree/polar> for more information on how to run the experiments. The sweeps have been changed to produce the plots in "Composite Polynomial Approximation of the Matrix Sign Function for the Muon Optimizer" (E. Erikson, 2026).
